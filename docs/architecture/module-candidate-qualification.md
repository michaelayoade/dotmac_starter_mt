# Prepublication candidate installation qualification

`release_module.py qualify-candidate DISTRIBUTION --dist dist --index "$INDEX" --output "$RUNNER_TEMP/candidate-qualified"` qualifies the already-built target wheel before upload. It never builds, publishes, tags, records a release, or creates admission authority. Run it in the authorized hosted environment with the existing hash-locked verifier dependencies. Source checks and authored tests alone are not genuine qualification evidence.

The target directory must contain exactly one regular wheel, matching the reviewed source distribution and version, and may also contain its corresponding `.tar.gz` sdist. The sdist filename must use the reviewed distribution (hyphens or normalized underscores) and exact reviewed version. Other files, duplicate wheels or sdists, directories, and symlinks are refused. Sdist filename validation is not sdist content qualification; the existing wheel-content inspection remains unchanged. The hosted caller snapshots and rechecks both build artifacts before upload. Existing wheel-content and native policies apply before resolution. The qualifier snapshots these exact bytes; the target is fixed as a local input to the unchanged V2 walker and is never downloaded by name. Reviewed manifest logical dependencies supply exact published pins. Kernel defaults to the highest reviewed closure `kernel_floor`; `--kernel` accepts an exact published version at or above that floor. Each logical member's installed version and manifest are independently checked.

Private-index-only resolution supplies every first-party dependency. Actual wheel METADATA supplies Python ranges without guessing sibling Python pins from checkout versions. Public-index resolution supplies only third-party dependencies. The shared binary-only, single-origin, no-dependency downloader, requirement parser, marker/extras/direct-reference refusal, and offline installer remain unchanged. The qualifier removes INDEX, PIP_*, TWINE_*, FORGEJO_* and private index URL environment variables from all subprocesses; the authenticated index is used only by the shared downloader's captured argument convention. The public index override remains available. Installed checks capture failures as generic errors.

A fresh isolated interpreter independently checks explicit wheel-path provenance, distribution ownership, installed manifests, ModuleRegistry composition and native extension loading. It installs all inspected wheels offline. After verification, source and first-party wheel hashes and the original candidate hash are rechecked. An exclusively created output directory contains only byte-exact qualified first-party wheels and `CandidateQualification.v1.json`, written last. Failure creates no usable receipt and never overwrites an existing output directory.

The receipt binds candidate filename/name/version/SHA-256, exact Kernel pin, logical module descriptors, every qualified first-party filename/name/version/SHA-256, and hashes of the release helper, reviewed allowlist, and closure source pyprojects/dossiers/manifests. It contains no index URLs or credentials. Its claim is `candidate-installation-only`; it carries no authorization, admission or publication proof. The hosted caller owns immutable run/source attribution, retention, and additional product-specific protocols against these exact wheels. A hosted caller can point `MODULE_RELEASE_CLOSURE_WHEEL_DIR` at this directory for the existing installed release fixture. Publication must still recheck original build artifact bytes and upload the same candidate bytes.
