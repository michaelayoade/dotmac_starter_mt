The assembly's Tailwind build scans `@source "../../templates"` — the kernel's packaged templates — and cannot see this file, so any utility class used only here would be PURGED from the compiled CSS. The screen would then render unstyled in production while looking correct in any dev build that happened to scan more. So a module's screens depend on the one thing contractually guaranteed to be present: the `dotmac-ui` design tokens, loaded by the assembly as a compiled, self-hosted stylesheet (ADR-0006 D3). Tokens are a published contract; the host's utility classes are its private build output. This is the compiled-asset boundary doing exactly the job it exists for.
