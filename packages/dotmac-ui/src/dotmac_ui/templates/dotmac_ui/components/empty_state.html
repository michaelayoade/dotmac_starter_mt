{# dotmac-ui component: empty_state Contract: dotmac_ui.components.EMPTY_STATE (signature, classes, stability). The "nothing to show here" panel for a list, table body, or card. Styling is entirely `.dmui-empty-state*` from the compiled stylesheet — no utility classes, because a consumer does not run this package through Tailwind and utilities would render unstyled from site-packages. Stock Jinja only: no custom filter, no global, no `url_for`. Everything it renders arrives as an argument, which is what lets it render on a bare Environment (see test_components_render_on_a_clean_host).
