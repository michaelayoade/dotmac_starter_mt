{# Standalone shell for the branded error pages. Error templates must NOT extend `base.html`: template composition puts the assembly layer first, so `base.html` resolves to the PRODUCT's shell, whose block contract is the product's own (`title`/`content` in Academy, for example). These pages override `body`, which a product shell is not contracted to define — when it does not, Jinja silently drops the whole error body and the user gets an empty branded shell. This layout is kernel-owned and only relies on kernel template globals (`brand`, `static_asset_url`, `extra_stylesheets`), so it renders identically in every assembly. A product that wants its own error look ships its own `errors/*.html` in its assembly layer, which still wins resolution. #} {% block title %}{{ brand.name if brand and brand.name else "Error" }}{% endblock %} {% for href in extra_stylesheets %} {% endfor %}
